# LetsMeet 

**LetsMeet** is an AI-powered platform designed to connect organizations hosting events with sponsors. Through match-scoring, it helps organizations find the right sponsors and allows corporations to discover high-ROI partnership opportunities.

## Getting Started

### Prerequisites
* Node.js
* Docker

### Backend
Head to the backend folder

```bash
cd backend
```

Run the docker (for database)
```bash
docker-compose up -d
```

Run the server
```bash
docker-compose up -d
```

### Frontend
Head to the frontend folder
```bash
cd ../frontend
```

Run the server  
```bash
npm run dev
```
